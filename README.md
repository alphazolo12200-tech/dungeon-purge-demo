# Dungeon Purge (Demo)

A top-down 2D survival game that runs in your browser. Fight zombies and monsters, loot weapons, and manage a shaped-item backpack that grows every level.

**This demo includes Levels 1-2 of the 12-level full game.**

## Play
Open `index.html` in any modern browser (Chrome, Edge, Firefox). No install, no build step, no dependencies.
Playable online via GitHub Pages: `https://alphazolo12200-tech.github.io/dungeon-purge-demo/`

## Controls
| Action | Key |
|---|---|
| Move | WASD |
| Aim | Mouse or Arrow keys |
| Attack / shoot | SPACE (hold) |
| Backpack | TAB |
| Quick weapons | 1-6 |
| Potion / Scroll | Q / E |
| Dash (Swiftness scroll) | SHIFT |
| Mute | M |

Backpack: click to pick up/place, R to rotate, right-click (or BACKSPACE) to equip/use, ENTER = click.

## Features
- Backpack starts at 5x4 and grows every level; every item has its own shape
- Knife, stealth knife, sword (with durability), handgun, revolver, shotgun
- Ammo types: light, heavy, shells
- Potions and scrolls: Vampirism, Swiftness, Bleeding, Fury
- Zombies, runners, spitters, brutes; all sound is generated in-browser
